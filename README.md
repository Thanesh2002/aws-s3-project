AWS S3 Static Website Project

 Project Overview
---This project demonstrates how to host a static website using AWS S3.  
   It includes a simple web application built using HTML and deployed on an S3 bucket with public access.

 ---
 Features
  - Static website hosting using AWS S3
  - Simple navigation (Home, About, Contact)
  - Lightweight and fast loading
  - Easy deployment without servers

 ---
 Technologies Used
  - HTML5
  - AWS S3 (Simple Storage Service)

 ---
How It Works
1. Created an S3 bucket
2. Enabled static website hosting
3. Uploaded HTML files
4. Configured bucket permissions (public access)
5. Accessed website using S3 endpoint URL
